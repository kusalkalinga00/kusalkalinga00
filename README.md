I like taking AI models out of demos and putting them into products — and I build the rest of the stack they need to live in: APIs, realtime systems, mobile and desktop apps.

- 🔭 Most recently: an image-generation app around a 7B model, a Go-based scraping engine, and a macOS menu bar app
- 🌱 Deep-diving into **RAG pipelines, realtime systems, and LLM-powered apps**

### Featured Projects

- 🔍 [Go Base Web Scraper](https://github.com/kusalkalinga00/go-base-web-scraper) — API-only scraping engine in Go: Chromium/Colly/PDF fetch paths, Redis Streams job queue, PostgreSQL results, SSRF guard.
- 🎨 [Latent — Image Generator](https://github.com/kusalkalinga00/latent-image-generator) — image generation & editing around a 7B model: drop a photo to edit it, or describe one to create it from scratch.

- ✏️ [Excalidraw Realtime Clone](https://github.com/kusalkalinga00/excalidraw-realtime-clone) — collaborative whiteboard with low-latency realtime sync via React, Hono, and Cloudflare Workers.
